XUAT BAN WEBSITE DE TAO LINK CONG KHAI (GITHUB PAGES)
1. Tao tai khoan GitHub neu ban chua co, sau do tao repository moi ten phan-anh-portfolio va chon Public.
2. Dung GitHub Desktop de them thu muc portfolio nay lam repository local, roi chon Publish repository.
   Dam bao repository la Public. Neu GitHub Desktop hoi tao repository, hay chon thu muc portfolio nay.
3. Day tat ca noi dung thu muc len nhanh main, bao gom index.html, css/, js/, reports/ va .github/.
4. Tren GitHub, vao Settings > Pages va chon GitHub Actions trong phan Build and deployment.
5. Mo tab Actions va doi workflow "Deploy portfolio to GitHub Pages" chay xong.

Link se co dang https://TEN_GITHUB_CUA_BAN.github.io/phan-anh-portfolio/
Sau moi lan cap nhat va publish len nhanh main, GitHub Pages se tu cap nhat website.
Luu y: repository Public va cac file PDF trong reports/ se duoc moi nguoi truy cap.
